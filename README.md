# Chemistry CT — тема 1, § 1–12

Статический учебный сайт на HTML, CSS и JavaScript. Не требует сборки, npm, сервера или внешних библиотек.

## Что внутри
- Подробная теория для 12 параграфов темы «Первоначальные химические понятия».
- Схемы и иллюстрации как встроенная SVG-графика: отдельных файлов изображений нет.
- Пошагово разобранный пример в каждом параграфе.
- По 4 интерактивных вопроса на параграф; проверка ответа и объяснение.
- Навигация по параграфам, поиск по названиям и кратким описаниям.
- Отметки прохождения сохраняются в `localStorage` текущего браузера.
- Адаптивная вёрстка для компьютеров и телефонов.

## Локальный просмотр
Откройте `index.html` в браузере. Для обычного статического сайта этого достаточно.

## Публикация в отдельном репозитории `chemistry-ct`
1. Распакуйте архив.
2. Загрузите **содержимое папки** `chemistry-ct` в корень репозитория `chemistry-ct` (файлы `index.html`, `styles.css`, `app.js`, `lessons.js`, `README.md`).
3. В GitHub откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем Save.
5. После публикации сайт отдельного репозитория обычно будет доступен по адресу `https://marinaklincevic-stack.github.io/chemistry-ct/`.

## Важно — не затрагивать первый сайт
Не загружайте эти файлы в старый репозиторий пользовательского сайта. Этот проект подготовлен отдельно именно для `chemistry-ct`; публикация в новом репозитории не меняет файлы первого сайта. Перед загрузкой проверьте, что в шапке GitHub открыт репозиторий `chemistry-ct`.

## Структура
- `index.html` — разметка и контейнеры интерфейса.
- `styles.css` — оформление и адаптивность.
- `app.js` — навигация, отрисовка уроков, тесты и прогресс.
- `lessons.js` — учебный контент всех 12 параграфов.
